# QuantumComp

Uma visualização interativa de um qubit em uma esfera de Bloch, desenvolvida como parte de um projeto de divulgação científica apresentado na Feira de Ciências do segundo ano do Ensino Médio.

## Visão geral

O objetivo deste projeto foi transformar um conceito abstrato da física quântica em algo visual, intuitivo e didático. A ideia central era mostrar como um qubit pode ser representado em uma esfera de Bloch e como diferentes estados quânticos podem ser interpretados geometricamente.

Esse repositório funciona como uma demonstração educativa e visual de conceitos como:

- superposição;
- estados quânticos;
- representação geométrica em uma esfera de Bloch;
- interpretação de fase e amplitude;
- introdução à mecânica quântica de forma acessível.

## Contexto da Feira de Ciências

Este projeto não foi pensado como uma aplicação de produção isolada, mas como parte de uma apresentação maior em uma Feira de Ciências. Em outras palavras, ele era uma peça complementar de um trabalho mais amplo, usado para ilustrar e explicar melhor os conceitos teóricos em linguagem acessível para o público.

A proposta era conectar a teoria à prática, mostrando que ideias aparentemente complexas da física quântica podem ser compreendidas por meio de modelos visuais e experimentos interativos.

## O que o projeto mostra

A interface permite visualizar um qubit em uma esfera de Bloch, com parâmetros que influenciam sua posição e sua representação no espaço. A partir disso, é possível discutir:

- a diferença entre estados clássicos e quânticos;
- o papel da superposição;
- como a fase interfere na representação do estado;
- a importância da visualização para a compreensão de temas avançados.

## Tecnologias utilizadas

Este projeto foi implementado com tecnologias web modernas, principalmente:

- React
- Vite
- JavaScript
- Three.js
- p5.js
- Chart.js

Essas ferramentas foram escolhidas para permitir uma interface visual dinâmica e uma experiência mais didática durante a apresentação.

## Estrutura do projeto

- `src/` — código principal da aplicação visual
- `public/` — arquivos públicos e recursos do projeto
- `docs/` — documentação e materiais auxiliares
- `llm-server/` — parte do projeto relacionada a integração com IA / servidor LLM
- `widgets/` — componentes e módulos adicionais

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/ThomyThom/QuantumComp.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd QuantumComp
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie a aplicação:

   ```bash
   npm run dev
   ```

5. Abra o endereço exibido no terminal no navegador.

## Objetivo pedagógico

Além de ser uma demonstração visual, o projeto tinha um papel pedagógico importante: tornar a física quântica menos distante da realidade do aluno e mostrar que conceitos de alta complexidade podem ser apresentados de forma clara, criativa e acessível.
